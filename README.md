"# JavaScript-JQuery-Minggu-6-" 

1.	Jelaskan secara singkat apa itu JavaScript dan kegunaannya!
    Jawab: JavaScript adalah bahasa pemrograman yang tidak memerlukan compiler dalam menajalankannya dan
    biasanya digunakan dalam pengembangan website agar lebih dinamis dan interaktif.
  	
2.  Jelaskan secara singkat apa itu jQuery dan kegunaannya!
    Jawab: JQuery adalah library JavaScript yang digunakan untuk mempercepat proses pembuatan website. Dengan
    JQuery kita bisa membuat berbagai macam efek dan animasi menarik pada website yang sedang dikembangkan.
    
3.  Jelaskan perbedaan JavaScript dan jQuery!
    Jawab: JavaScript merupakan bahasa bahsa pemrograman, dan sedangkan jQuery adalah library atau kumpulan
    fungsi siap pakai yang dibangun menggunakan JavaScript.
